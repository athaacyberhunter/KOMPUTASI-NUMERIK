# Algoritma Penyelesaian SPL 3 Variabel (Eliminasi Gauss)

Sistem Persamaan Linear 3 Variabel memiliki bentuk umum:
- a11*x + a12*y + a13*z = b1
- a21*x + a22*y + a23*z = b2
- a31*x + a32*y + a33*z = b3

## Langkah-Langkah Algoritma:

1. **Mulai (Start)**
2. **Input Matriks Augmented:**
   Masukkan koefisien variabel dan konstanta hasil ke dalam matriks ukuran 3x4, sebut saja matriks `A` dengan elemen `A[i][j]` untuk `i = 0, 1, 2` dan `j = 0, 1, 2, 3`.
3. **Proses Eliminasi Maju (Forward Elimination):**
   Ubah matriks `A` menjadi matriks segitiga atas (elemen di bawah diagonal utama bernilai 0).
   - Untuk `i` dari `0` sampai `1`:
     - Cek elemen pivot `A[i][i]`. Jika `A[i][i] == 0`, tukar baris `i` dengan baris di bawahnya yang memiliki elemen tidak nol pada kolom `i` (*Partial Pivoting*).
     - Untuk `k` dari `i + 1` sampai `2`:
       - Hitung faktor pengali: `faktor = A[k][i] / A[i][i]`
       - Untuk `j` dari `i` sampai `3`:
         - Update elemen baris: `A[k][j] = A[k][j] - faktor * A[i][j]`
4. **Cek Solusi Unik:**
   Jika `A[2][2] == 0`, tampilkan pesan *"Sistem tidak memiliki solusi unik"* dan hentikan program.
5. **Proses Substitusi Balik (Back Substitution):**
   Hitung nilai variabel mulai dari baris paling bawah ke atas:
   - `z = A[2][3] / A[2][2]`
   - `y = (A[1][3] - A[1][2] * z) / A[1][1]`
   - `x = (A[0][3] - A[0][1] * y - A[0][2] * z) / A[0][0]`
6. **Output:**
   Tampilkan nilai solusi `x`, `y`, dan `z`.
7. **Selesai (End)**
